# 먼작귀

치이카와, 하치와레, 우사기가 macOS 데스크톱과 창 위를 돌아다니는 Swift/AppKit 팬 프로젝트입니다. 캐릭터 GIF와 미리보기 이미지를 함께 넣어 동작 디자인을 살펴보고, macOS에서 직접 빌드할 수 있습니다.

## 캐릭터와 동작

| 캐릭터 | 역할 | 움직임 |
| --- | --- | --- |
| 치이카와 | 자동화 검수 | 걷기, 춤추기, 엎드리기, 매달리기, 점프/낙하, 알림 달려오기 |
| 하치와레 | BOM 업무 | 걷기, 엎드리기, 매달리기, 점프/낙하, 기뻐하기, 알림 달려오기 |
| 우사기 | 회의·개인 일정 | 걷기, 엎드리기, 매달리기, 점프/낙하, 빙글빙글 돌기, 알림 달려오기 |

세 캐릭터는 각자 다른 속도와 동작 주기를 사용합니다. 우사기는 더 높고 멀리 점프합니다. 알림 테스트를 누르면 캐릭터들이 화면 아래에 나란히 달려옵니다. `Design/`에는 캐릭터 동작 모음과 앱 화면 미리보기가 있습니다.

현재 Monday.com 자동화, BOM 원격 동기화, 실제 캘린더 연동은 연결하지 않았습니다. 해당 화면과 알림은 프로토타입입니다.

## 빌드 및 실행

macOS 13 이상과 Xcode Command Line Tools가 필요합니다.

```sh
zsh scripts/build-app.sh
open dist/ChiikawaDesk.app
```

캐릭터 이미지 리소스는 `Sources/ChiikawaDesk/Resources/`에 있습니다. 애니메이션 배치와 이동 계산은 `Sources/ChiikawaDesk/`와 `Sources/PetGeometry/`에서 확인할 수 있습니다.

## 이미지 및 권리

캐릭터와 원작 이미지의 권리는 각 권리자에게 있습니다. 이 저장소는 비상업적 팬 프로젝트이며, 이미지에 대한 별도 이용 허락이나 상업적 사용 권리를 부여하지 않습니다.
